Notation: the parts of a BPMN diagram
A small set of shapes covers most processes: events, activities, gateways, flows and containers. Shape tells the kind, tint tells the role.
Events: something happens
Start
Where the process begins. Thin green ring.
Message start
Starts when a message arrives.
Timer
Wait, or a deadline. Double amber ring.
Message
Waits for or sends a message.
End
Where a path stops. Thick rose ring.
Error end
The path ends in failure.
Activities: work is done
Task
Task
A single unit of work.
User task
User task
A person does it.
Service task
Service task
A system does it.
Send task
Send task
Sends a message.
Receive task
Receive task
Waits for a message.
Sub-process
+
Sub-process
A task defined elsewhere (+).
Gateways: the path splits or joins
Exclusive
One exit is taken.
Parallel
All exits are taken.
Inclusive
One or more exits.
Event-based
First message wins.
Flows: what connects
Sequence flow
Order of work inside a pool.
Message flow
Between pools. Open circle, open head.
Return
Dashed slate: loop back or retry.
Main path
Blue, animated. One per diagram.
Containers: who does it
Pool
Pool
One participant: a company, a system or a role that takes part. Messages cross between pools.
Lane
Lane
Lane
A role or team inside one pool. Work crosses lanes with sequence flows.
