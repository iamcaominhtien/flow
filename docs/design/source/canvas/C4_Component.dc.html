Level 3, components: the Order service
Zoom into one container. A component is a part inside it: a controller, a handler, a client. Neighbours are shown as containers, because that is what they are from here.
Order service [Container]
API gateway
[Container: Kong]
Routing, auth checks.
Order controller
[Component: Spring REST]
Receives the calls from the gateway.
Checkout handler
[Component: Kotlin]
Validates the basket and drives checkout.
Payment client
[Component: gRPC]
Asks the payment service to charge.
Order state machine
[Component: Kotlin]
Placed, paid, cooking, on the way, delivered.
Event publisher
[Component: Kafka client]
Emits an event for every state change.
Order repository
[Component: Spring Data]
Reads and writes orders.
Orders database
[Container: PostgreSQL]
Orders, customers, menus.
Payment service
[Container: Kotlin, Spring]
Charges and refunds.
Event bus
[Container: Kafka]
Order and delivery events.
