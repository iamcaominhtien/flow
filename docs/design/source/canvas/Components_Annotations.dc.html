Special edges

Animated and emphasised lines. Use animation on one main path per diagram; a second animated line cancels the effect
Animated main pathThick blue line with moving dashes. Marks the happy path or the primary request route.dashed=1;flowAnimation=1;strokeWidth=4;strokeColor=#1D4ED8;endArrow=block;endFill=1;
Animated by outcomeGreen for the success route, rose for the failure route. Use only when the diagram compares the two.dashed=1;flowAnimation=1;strokeWidth=4;strokeColor=#15803D; / #B42318
Data streamHeavy solid line for a high-volume flow. No motion, so it reads as capacity rather than direction.strokeWidth=6;strokeColor=#475569;endArrow=block;endFill=1;
Two-wayHeads at both ends for a request that also returns data (read and write, sync).startArrow=block;startFill=1;endArrow=block;endFill=1;strokeWidth=2;
Optional linkDotted line with an open head: a loose or optional dependency.dashed=1;dashPattern=1 5;endArrow=open;strokeColor=#475569;strokeWidth=2;
