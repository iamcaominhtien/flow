1Screen IDS and a number. A letter marks a variant of the same screen (S01b is its error state).
2Device framePhone, tablet, desktop or watch, portrait or landscape. The screen content is built from wireframe blocks.
3HotspotRed dot with a halo on the element that was tapped. The arrow itself starts from the frame edge.
4Transition and action chipSolid arrow to the next screen. The dark chip names the gesture: tap, click, swipe.
5GuardThe condition that picks the path, in mono and square brackets. Green for success, rose for failure.
6Back or retryDashed slate arrow to an earlier screen. It shares the facing edge with the forward arrow, on the lower third.
