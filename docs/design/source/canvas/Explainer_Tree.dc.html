What is inside a web project
A project is a folder with a few well-known places in it. Knowing what each one is for makes any new project easy to read.
my-app/
The project folder. Everything below lives here.
src/
The code you write. Most of your time is spent here.
inside:components/pages/api/
public/
Files sent to the browser as they are: images, icons, fonts.
tests/
Small programs that check the code still works.
docs/
Notes for people: how to start, how it is built.
package.json
The shopping list: which libraries the project needs.
README.md
The front door: what this is and how to run it.
.env
Secrets such as passwords. Never shared, never uploaded.
Folder names end with a slash. Names with a dot are files. Order here is only for reading; real folders are listed alphabetically.
