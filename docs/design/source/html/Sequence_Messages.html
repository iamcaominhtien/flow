Message kinds
Every arrow style has one meaning. The line says how the call behaves, the colour says how much it matters. A plugin picks the style from the message kind, never by hand.

Synchronous call
Solid line, filled head. The caller waits for the answer.
kind: sync
Return
Dashed line, open head. Only drawn when the value matters.
kind: return
Asynchronous message
Solid line, open head. The caller carries on.
kind: async
Self call
The service calls itself. The loop leaves the lifeline and returns.
kind: self
Lost message
Sent, but nobody receives it. Ends in a filled dot.
kind: lost
Found message
Comes from outside the diagram. Starts from a filled dot.
kind: found
Create
Dashed line into a box that appears lower. The lifeline starts there.
kind: create
Destroy
A rose cross ends the lifeline. Nothing is drawn below it.
kind: destroy
Main path
Blue, thick, animated. The one route that matters. Return and async keep their head.
role: main
Failure
Rose. Label in rose. The branch that goes wrong.
role: fail
Event stream
Violet, thin, slow animation. Messages that flow without waiting.
role: event
Numbers are optional. Branches use a letter: 6a, 6b. A label is one short phrase above the line, the call written like code or a short noun.
