Rules for overlaysModal and bottom sheet dim the screen under them (dark scrim). The dimmed screen stays visible, so the user's context is clear.Toast does not dim anything and leaves by itself: use a slate "auto" chip for the return arrow.Dismissing (cancel, tap outside, back) is a dashed arrow back to the base screen. A confirming action is a solid arrow, with its effect after the slash.Name the frame with the base screen ID plus the overlay kind, for example S12 + modal. Give an overlay its own number only when it has onward transitions of its own.
