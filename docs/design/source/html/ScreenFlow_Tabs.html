How to draw tab navigationOne bus line into all tabs means "any tab to any other tab". Do not draw each pair.The active tab is blue in the bar inside each frame, so the stack a screen belongs to is visible at a glance.A screen that hides the bar (checkout, player, camera) goes outside the blue zone, in its own zone.Each tab keeps its own history: leaving and coming back returns to the screen where the user left off.
