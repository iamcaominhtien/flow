What starts the change: a chip, dark for the user, slate for the system. [guard]
The condition that must be true. Mono, in square brackets. / effect
What happens on the way: save, request, clear. Optional.

User action

Always verb plus target: tap, double tap, long press, click, drag, type, scroll to end. Dark chip, no icon.

Time

auto 2 sidle 30 s

The screen changes by itself: splash timer, session timeout, polling. Slate chip with a clock.

System event

push openeddeep link

Something outside the screen fires: push, deep link, app resumed, battery low. Slate chip with a bolt.

Permission and auth

OS promptsign-in

Camera, location, notifications, biometrics, login. Usually followed by a decision with [granted] and [denied].

Network and API

API resultoffline

A response, a timeout or no connection. Put the outcome in the guard: [200], [401], [timeout].

Device

back buttonrotate

Hardware actions: back button, rotate, shake, volume key. Slate chip with a phone outline.
