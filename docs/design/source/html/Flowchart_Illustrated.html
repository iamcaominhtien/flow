Illustrated nodes
An optional richer style for work steps: a name pill, one line of explanation and a large icon on a card tinted by its lane. Use it for the steps that matter or when the chart is for people outside the team. Plain nodes stay the default.

Choosing icons
  • Match the noun, not the verb: Card for authorize card, Restaurant for pick up.
  • One icon per card. Never two, never an icon that only decorates.
  • The same thing gets the same icon everywhere in the chart.
  • Take icons from the detailed set on the Icons page. If none fits, draw one in the same style: 64 grid, 2.5 px ink outline, three tones.
  • Icons are optional. A card without an icon is allowed, but keep its text width.

Spacing
  • Card 232 × 96 with a 64 px icon. Plain node 160 × 56. Screen card 150 × 92 with a Mobile icon.
  • Gap between cards in a row: 90 px or more, 130 px when a trigger chip sits on the arrow.
  • Lane height: 240 px with cards, 210 px with plain nodes. A lane holding both uses 240.
  • Vertical gap between rows of cards: 56 px or more.
  • Fork and join bars span the lanes they split and sit 90 px from the cards they feed.
