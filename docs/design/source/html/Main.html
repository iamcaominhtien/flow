Flow Foundation · v0.1 draft

Visual foundation for draw.io diagrams

Colors, type, shapes, edges and themes shared by every Flow plugin, so a flowchart, an ER diagram and an architecture map all look like one family. Each token carries the draw.io style value the plugins will write into the XML.

Color

Six pastel families. Each has a tint for fills, a stroke for outlines and an accent for pills and emphasis. Tint + ink text is the default pairing for nodes.

Typography

Inter for every diagram label, JetBrains Mono for code, paths and field names. Sizes are in draw.io points at 100% zoom; nothing in a diagram goes below 10.

Themes

A theme swaps the palette, corner radius and edge style while keeping the same shapes and spacing. Plugins take a theme name and apply it to the whole diagram.

Layout rules

Grid

10 px

Snap every shape and waypoint to a 10 px grid.

Spacing

40 / 60 px

Gap between siblings in a row, and between tiers.

Radius

12 / 14 / pill

Nodes 12, containers 14, titles fully rounded.

Strokes

2 / 1.5 px

Nodes and outlines 2, edges 1.5, containers dashed 1.5.
