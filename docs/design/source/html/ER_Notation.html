Badges
PK primary key, FK foreign key, UQ unique. A column can carry two, such as PK FK in a junction table.
Bold name
The primary key is bold. Keys come first, then the columns that explain the relationships.
Type
Mono, grey, right aligned. Generic names: uuid, text, int, decimal, bool, timestamp.
Question mark
A ? after the type: the column may be empty.
