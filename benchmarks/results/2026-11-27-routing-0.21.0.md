# Routing of 0.21.0 (the entry skill `flow:draw`) against 0.20.0

Date: 2026-11-27. Set, harness and rule: `benchmarks/routing/` (rule committed in `c90ee95`, changed to Sonnet only in `57dd253` before any baseline finished). Every run: Sonnet (`claude-sonnet-5-5`), stopped at its first decisive event. Plugin versions: 0.20.0 (`57dd253`) and 0.21.0 (`a1cd317`). Reviewed by an independent agent at the design, the plan and the diff.

## Verdict

**By the rule: kept.** On the held split, misses fell from 10 to 3 of 30, false positives stayed at 0 of 16, and in the clean environment hits rose from 11 to 14 of 15. A second run of 0.20.0 on the held split after the final runs gave 21 of 30, so the gain is not drift over time.

**But the entry skill is not how it was won, as far as this shows.** `flow:draw` was loaded in 2 of 46 final held runs; the other new hits went straight to a type skill. What moved the agent is not measured; a likely reading, not verified, is that one description that says "draw, show, picture, visualise ... from any input" makes the plugin as a whole look like the tool for such requests. On twelve fresh requests written by an agent that had not seen the description, the two versions are equal (8 of 16 each), and there `flow:draw` was never loaded.

Per held request (old: 4 runs, new: 2), the new version has the higher hit rate on 5 requests and the lower on none. Flow's skills were listed to the agent in every run.

## What is left

- **The agent answers in words when the request asks to understand something.** Every fresh miss (8) is a text answer to requests like "show me what happens from the moment a refund is requested", "help me see how the services talk to each other", "cho mình xem luồng xử lý của một request". The agent reads the code and explains it in markdown without considering a picture. Whether a diagram plugin should take such requests at all is a product decision for the owner, not a routing bug; nothing was changed for it.
- **The hosted `Artifact` tool** of this cloud harness took p15 in every run (its instructions say to call it first for any page). A user's own install does not have it; not addressed.
- **Not measured:** whether a run that loads Flow stays with it to the end, and any model but Sonnet.

## Validity notes

- The per-request decisions of the held baseline were printed once while summarising; no held log was read before the final run, and `flow:draw` was designed from the dev logs.
- The requests and the description share a writer, so the held split is not independent of the description's words; the fresh set is the check on that, and it shows no gain.
- `rescore.py` replayed the baseline under the harness's later rule for shell redirects: four runs changed label (`own:svg` to `own:bash`), no total changed. Loading `flow:draw` was made non-decisive, which is stricter on the new version.
- Cost: about 270 runs, roughly $20, plus the reviews.
